## 目的

日本食の地理データベース「Itadaki Atlas」（主対象は海外の読者。KGI は送客。「土地と食の因果」を語る媒体。ランキング・煽り禁止）の県ページ `/region/<pref>` と、トップで県を選んだ直後の画面には、今は件数と一覧しか出ていない。サイトの体験原則2「**選択の直後に必ず文脈を出す**（件数の前に「これは何か」）」を県でも満たすため、47都道府県それぞれに**一行の総論**を書く。あわせて、送客先が実在する旗艦の**石川県だけ**、県ページの読み物（地の文）を書く（ロードマップ P2-3。ユーザー選択 2026-10-04「47県の一行＋石川の地の文」）。

## 一行の総論（全ブロック。担当県すべて）

| キー | 内容 |
| :--- | :--- |
| `pref` | 都道府県の正式名（「北海道」「東京都」「京都府」「石川県」） |
| `intro_ja` | 100〜180字。**土地の条件（海・山・川・雪・盆地・火山・街道・城下町・港・寺社）→ そこで何が生まれ・育ち・仕込まれるか → 収録アイテムから代表2〜4件の名前**、の順で1〜2文。「この土地で生まれた」「この土地が育てる」「この土地が仕込む」の語彙を使ってよい |
| `intro_en` | 同内容の自然な英語（直訳しない）。50〜100 words。日本語の料理名は初出でローマ字＋短い説明（"jibuni — duck simmered in a thickened broth"） |
| `sources` | 1本 `{title,url,publisher,accessed_at}`（下記「出典」） |
| `notes` | 任意。裏が取れず書かなかったこと・要判断 |

書くこと・書かないこと:

- **因果で書く。** 「寒流と暖流がぶつかる沖で獲れる魚と、それを干し・漬ける冬の仕事」のように、土地の条件が食の形を決めたことが一文で伝わるように。観光案内の形容（「食の宝庫」「グルメ王国」「美味しいものがたくさん」）は書かない
- 代表の選び方は**索引の born / raised / honba から、その県の性格を一番よく表すもの**。件数の多い順ではない。人気・有名を理由にしない（「有名な」「人気の」「一番」「三大」「No.1」と書かない）
- 「ご当地」「Regional」を使わない（体験原則3）
- 断定しない（「〜とされる」「〜という」「〜と伝わる」）。「〜だ。」の断定終止を使わない
- 県全体を一言で決めつけない。南北・東西・山海で性格が分かれる県は、分かれていること自体を書く（北海道の道南・道東、長野の北信・南信、静岡の東西 など）

### 文体見本（架空。この粒度で）

> 寒流と暖流がぶつかる沖の魚と、雪に閉ざされる冬を越すための干物・漬物が、この土地の食の骨格とされる。港で揚がった魚を酢や麹で仕込む保存の仕事が残り、ハタハタのしょっつるや、米どころの酒・麹の文化と結びついているという。

## 石川の地の文（ブロック E のみ）

| キー | 内容 |
| :--- | :--- |
| `body_ja` | Markdown。1,500〜2,200字。見出し `## ` で4〜5章。見出しは普通の語で（例: 「海と港」「城下町の台所」「発酵と保存」「加賀野菜」「能登の里山と里海」。凝った見出しを発明しない） |
| `body_en` | 同内容の自然な英語（直訳しない）。見出しも英語で |

- 章ごとに「土地の条件 → 食の形」の因果を1本通す。年表にしない（歴史は「この一品がこうなった理由」としてだけ書く）
- 収録アイテムへのリンクを本文中に張る: `[かぶら寿し](/sushi/kaburazushi)` の形（URL は索引の `url`、かつ slugs-by-genre.txt にあるものだけ）。1章に2〜4本
- 金沢と能登、加賀の違いを書き分ける（城下町の料理と菓子・近江町の市場／能登の塩・いしる・里海／加賀の温泉地と野菜）
- **2024年の能登半島地震と豪雨**: 能登の章で一度だけ事実として触れる（「2024年の地震と豪雨で能登の生産者や店は大きな被害を受け、営業状況は場所によって異なる。訪ねる前に最新の情報を確かめてほしい」程度）。復興の進み具合を推測で書かない・感傷的に書かない
- 店名・値段・ランキング・受賞歴は書かない。「食べに行く前に」ガイドがある話題（近江町市場の歩き方など）は本文で深入りしない
