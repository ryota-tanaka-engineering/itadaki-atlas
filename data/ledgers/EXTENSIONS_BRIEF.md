## タスク styles: ジャンルページの系統ごとの一文解説

入力 `{{input}}`（ジャンル → 系統 → 件数と代表アイテムの名前・要約）。ジャンルページでは系統ごとに見出しを立てて一覧を出しているが、見出しは「醤油」「白身」「芋」のような名前だけで、海外の読者には何の区分か分からない。各系統の見出しの直下に置く一文を書く。

| キー | 内容 |
| :--- | :--- |
| `genre` / `style` | 入力と同じ値（style は日本語のまま。キーになる） |
| `intro_ja` | 40〜90字・1文。**その系統を他と分ける実体**（スープの素・魚の身の質・原料・製法）と、**食べると何が違うか**。代表アイテムを1〜2件挙げてよい |
| `intro_en` | 同内容の自然な英語。20〜45 words |

- 「その他」系統も書く（「上の系統に収まらない型。〜のように〜」の形で、何が入っているかを具体例で言う）
- ラーメンの「産地」ではなく、日本茶の「産地」系統は「産地名で呼ばれる茶」の意味。入力の例から判断する

出力: `{"styles":[{"genre","style","intro_ja","intro_en"}],"notes":"…"}`

## タスク tags: タグの総論と英語の定義

入力 `{{input}}`（タグごとに slug・種別・日英の名前・日本語の定義・件数・例）。タグページ `/tag/<slug>` は今、日本語の定義一文と一覧しか無く、**英語ページにも日本語の定義が出ている**。

| キー | 内容 |
| :--- | :--- |
| `slug` | 入力と同じ |
| `definition_en` | 日本語の定義（`definition_ja`）の英語版。1文・15〜35 words。定義なので解釈を足さない |
| `intro_ja` | 80〜150字。**このタグで束ねると何が見えるか**（例: 「凍み技法」＝寒冷地で凍結と乾燥を繰り返す保存。凍み豆腐・凍み大根・凍みこんにゃくのように素材を越えて同じ仕事が北の山間に分布する）。例から2〜3件の名前を挙げてよい |
| `intro_en` | 同内容の自然な英語。40〜80 words |

- 件数が5未満のタグ（insect・postwar_us_military・kelp_cured・no_broth 等）も書く。少ないこと自体は書かない
- 「行事食（ceremonial）」「場面」系のタグは、場面の説明に寄せすぎず「何の日に・なぜその形か」を書く

出力: `{"tags":[{"slug","definition_en","intro_ja","intro_en"}],"notes":"…"}`

## タスク chains: チェーン創業メモの英訳

入力 `{{input}}`（チェーン133件。`founded` が日本語の創業メモ。例「1960年・福岡市（屋台として創業したとされる。…）」）。英語ページでは創業メモが出ていない（日本語の列しか無いため）。

| キー | 内容 |
| :--- | :--- |
| `slug` | 入力と同じ |
| `founded_en` | `founded` の英語。**事実の翻訳だけ**（足さない・削らない）。年・地名・「とされる」の留保を保つ。地名はローマ字（"Fukuoka"、区は "Chuo Ward, Tokyo"）。1〜2文 |

- 社名・人名はローマ字。社内の称号や宣伝文句が混じっていれば訳さず `notes` に残す
- 日付の書式: "Founded in 1960 in Fukuoka (said to have started as a street stall; …)."

出力: `{"chains":[{"slug","founded_en"}],"notes":"…"}`
