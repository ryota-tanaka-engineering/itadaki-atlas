# 目的

Itadaki Atlas が置かれた競合環境と、差別化の構造を定義する。

## 1. 競合マップ

| 区分 | 代表例 | 強み | 弱み（本プロダクトの機会） |
| :--- | :--- | :--- | :--- |
| **世界の食を網羅する地図型メディア** | TasteAtlas | 世界規模の網羅性・地図体験・ブランド認知 | **日本の粒度が浅い。** 「ramen」で括られ、ご当地の細分化に届いていない |
| 百科事典 | Wikipedia | 情報量・信頼性 | 地図で引けない。旅行者の「今どこで何を食べるか」に答えない |
| 旅行ガイド | Japan Guide 等 | 英語での旅行文脈 | 食は数ある項目の1つ。網羅も深さもない |
| 個人ブログ・YouTube | — | 熱量・実体験 | 体系化されていない。横断して引けない |
| 予約・口コミ | 食べログ / Google Maps | 店の評価 | **料理そのものの由来を扱わない。** 店を探す道具であって、食を理解する道具ではない |

## 2. 空白地帯

**「家系・二郎系より細かい粒度で、英語圏に整理されたコンテンツ」は現状存在しない。**

日本語圏には断片的な情報が大量にあるが、次の3つを同時に満たすものがない。

1. 超細分類（ご当地ラーメン約180種のレベル）
2. 地図から引ける
3. 英語で読める

日本語の情報が豊富であるがゆえに「英語に整理し直す」インセンティブが働かず、逆に英語圏の事業者は日本の粒度に踏み込めない。**この非対称性が空白を生んでいる。**

## 3. 差別化の3点

| # | 差別化要素 | 模倣困難性 |
| :--- | :--- | :--- |
| **①** | **日本特化の深さ** — ご当地ラーメン約180種の網羅 | 中。時間をかければ模倣可能だが、一次情報の精度で差がつく |
| **②** | **地図体験の美しさ** — スマホファーストの地図UX | 低〜中。技術的には模倣可能 |
| **③** | **実際に案内できる出口** — 既存事業（旅程プランニング・ラーメンエージェント）への接続 | **高。メディア単体の競合には構造上模倣できない** |

③が本質的な堀である。TasteAtlas は「知る」で終わるが、Itadaki Atlas は**「知る → 行く」まで繋げられる**。この接続は、送客先の事業を自前で持っていて初めて成立する。

## 4. 品質基準としての「日本人が見ても見たいレベル」

差別化①を成立させる具体的な基準として、**国内でも話題になる深さ**を置く（雑煮の地域差、出汁の東西比較）。

これは対外的な差別化であると同時に、**国内トラフィックを取る戦術**でもある。「英語圏向けだから浅くてよい」という妥協を許すと、①が崩れて②だけの勝負になり、模倣困難性を失う。

## 5. 参入障壁の構築順序

初期は差別化が弱い（データ量が少なく、出口も細い）。**時間とともに堀が深くなる**構造を意識して積む。

1. **フェーズ1〜2:** データ量と品質で②③を補う。この時期は最も脆い
2. **フェーズ2〜3:** ジャンル横断のリレーション（`food_item_relations`）が蓄積し、**単体記事の集合では再現できない回遊構造**が生まれる
3. **フェーズ3以降:** 既存事業への送客実績が積み上がり、③が営業上の実績として機能する。掲載事業者との関係自体が資産になる
