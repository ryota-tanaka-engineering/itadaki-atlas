# 目的

Itadaki Atlas のブランド定義（MVV・Value Proposition・Tone & Manner・表記ルール）を定める。コンテンツ執筆とUI文言の判断基準。

## 1. 名称

**Itadaki Atlas**（イタダキ アトラス）

- `Itadaki` — 「いただきます」に由来する。食べる行為への敬意を含む日本語であり、英語圏にもローマ字表記のまま届く音
- `Atlas` — 地図帳。本プロダクトが「記事の集合」ではなく**体系化された地理データベース**であることを名前で宣言する

競合なしを確認済み。ドメイン `itadakiatlas.com`、SNSハンドルは `@itadakiatlas` で統一（X / Instagram / TikTok / YouTube）。

将来 Itadaki を冠する別サービス（温泉等）を展開しうるため、**`Itadaki` をブランドの傘、`Atlas` を本サービスの識別子**として扱う。

## 2. MVV

| | 内容 |
| :--- | :--- |
| **Mission** | 日本の食を、土地との因果ごと記録し、世界から引けるようにする |
| **Vision** | 「何を食べているか分からない」を理由に、日本での食の体験を諦める人をなくす |
| **Value** | **正確であること。** 深いこと。中立であること。この3つを、速さより優先する |

## 3. Value Proposition

| 相手 | 提供価値 |
| :--- | :--- |
| **海外（英語圏）旅行者** | メニューが読める。何を食べているか分かる。その土地でしか食べられないものが分かる |
| **国内ユーザー** | 日本人が読んでも発見がある深さ。雑煮の地域差や出汁の東西のような、話題にしたくなる知識 |
| **掲載事業者・自治体** | 中立な媒体に、正確に、英語で掲載される |

## 4. Tone & Manner

### 4.1 基本姿勢

**レファレンスの声で書く。** 熱量で押さない。

| ✅ 採る | ❌ 採らない |
| :--- | :--- |
| 事実と由来を淡々と述べる | 「絶対に食べるべき!!」のような煽り |
| 読者が自分で判断できる材料を出す | ランキングで優劣を断定する |
| 分からないことは「諸説ある」と書く | 断定して権威的に見せる |
| 土地を主語にした因果を説明する | 感想文・食レポ |

理由は North Star にある。**煽りは短期のPVを生むが、信頼を削る。** そして本プロダクトのKGIはPVではなく送客であり、送客は信頼がなければ起きない（`.doc/00_concept/01_north_star.md` §3）。

### 4.2 英語表現

- 日本語をそのまま直訳しない。**説明訳**を使う
- 英語圏の読者が持っていない前提（出汁・こしの概念など）は、省略せず短く説明する
- 過度にエキゾチックに演出しない。「神秘の国ニッポン」のトーンを避ける

### 4.3 UI文言

- 簡潔。地図を主役にするため、UI文言は最小限に留める
- ボタンは動作を書く（「探す」「地図で見る」）。凝った言い回しをしない

## 5. 名称表記ルール（重要）

すべてのアイテムで **「日本語名 — ローマ字 — 英訳」の三点セット**を守る。

```
せせり — Seseri — chicken neck meat
家系  — Iekei  — rich pork-soy broth style
```

| 要素 | 役割 |
| :--- | :--- |
| **日本語名** | 実際のメニューとの照合。これが無いと店で注文できない |
| **ローマ字** | 発音して伝えられる |
| **英訳（説明訳）** | 何であるかが分かる。**直訳ではなく説明訳** |

この三点セットは装飾ではなく、ミッション②「メニュー解読」を成立させる**機能要件**である（`.doc/30_features/01_requirements.md` F-04）。

## 6. ビジュアル方針

| フェーズ | 主軸 |
| :--- | :--- |
| 1 | **系統色**（写真・イラストなし）。色がアイコンの役割を担う |
| 2 | **統一イラスト**。スタイルを確定させてから量産する |
| 収益化後 | 実写（タイアップ提供 or 出稿商材として差し替え） |

イラストの生成方針・レビュー工程・禁止事項は `.doc/40_operation/01_strategy.md`。

**他サイトからの画像・文章の転載は全面禁止。** 法人運営・営業信用の観点から、例外を設けない。

## 7. ブランドを毀損する行為

- PR表記のない広告掲載
- 出典を示さない断定
- 実際に案内できない店・体験への送客
- 「英語圏向けだから」を理由にした内容の劣化
