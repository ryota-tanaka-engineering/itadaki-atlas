# 目的

Itadaki Atlas の事業展開スケジュールとフェーズ別KPIを定義する。

## 1. フェーズ1（MVP）のマイルストーン

実装対象は「ご当地ラーメン約180種を地図＋索引で公開」（`.doc/30_features/01_requirements.md`）。

| # | 内容 | 完了条件 |
| :--- | :--- | :--- |
| **M1** | スキーマ実装 + CSVインポート | 約180種がDBに入りバリデーションを通過する |
| **M2** | 地図表示（MapLibre + ピン + 系統色） | スマホで約180種が地図表示される |
| **M3** | ボトムシート + 索引 | 3段階スナップと3軸索引が動作する |
| **M4** | ディフォルメ地図の切り替え | ズームレベルに応じた切り替えが動作する |
| **M5** | 詳細ページ + 英日切替 + SEO | Lighthouse a11y 90+、公開可能状態 |

### 着手前に決めておく事項

| 対象 | 期限 |
| :--- | :--- |
| ドメイン `itadakiatlas.com` とSNSハンドルの取得 | 実装着手前 |
| `japan.pmtiles` の生成とR2配置 | M2 着手前 |
| ディフォルメ地図の実装方式 | M4 着手前 |
| イラストのスタイル確定（フェーズ2向け） | フェーズ2着手前 |

## 3. フェーズ2

| # | 内容 | 目的 |
| :--- | :--- | :--- |
| P2-1 | 詳細属性の拡充（特徴タグ・麺・濃度・歴史・元祖店） | フィルタとして機能する構造化タグを揃える |
| P2-2 | イラストの導入 | スタイル確定プロセス（§5）を経てから量産 |
| P2-3 | **地域ページの開栓（旗艦＝金沢/石川）** | 第二のSEO正面。送客先が実在する地域で型を作る |
| P2-4 | フィードバックフォーム・未掲載投稿フォーム | DB成長の燃料 |
| P2-5 | `food-recommend` との好みマッチング連携 | 既存事業とのデータ接続 |

地域ページを金沢/石川から始めるのは、**インバウンド事業の実地知識があり、送客先が実在する**ため。型ができてから他地域へ展開する。

## 4. フェーズ3以降: ジャンル展開の登り順

展開順は「重複項目の多さ」「既存事業とのシナジー」「検索需要」で判断する（`.doc/00_concept/04_strategy.md` §3.2）。

| 順 | ジャンル | 狙い |
| :--- | :--- | :--- |
| **1** | ラーメン（フェーズ1） | **ジャンル軸 × 地図の型を検証する** |
| **2** | 焼き鳥（部位図鑑 + ご当地焼き鳥） | **メニュー解読型の検証。** 約40部位で軽量、英語検索需要あり、解剖図イラストがSNS素材として最強。やきとんへ横展開できる |
| **3** | 寿司 × ネタ | **SEO最大の賞金首**（"types of sushi"）。二層構造 + 写真必須で重いため、型が揃ってから |
| **4** | 和牛 または 牡蠣 | **食材展開型の検証。** 和牛は約30ブランドで検索需要大・富裕層インバウンド直結。牡蠣は既存の牡蠣コミュニティ事業とのシナジーと一次情報の独自性。順序は牡蠣事業の動き次第で入替可 |
| **5** | 3〜4ジャンル揃った時点で**地域ページを本格展開** | エリア軸が機能する条件が揃う |

### バックログ（順不同）

| 類型 | 候補 |
| :--- | :--- |
| **dish列挙型**（ラーメンと同構造） | 餃子、うどん、そば、粉もの、洋食（味噌カツ・カツカレー等）、串カツ、雑煮（47県バリエーション） |
| **食材展開型**（二層構成） | 寿司×ネタ、天ぷら/フライ×食材、焼き鳥×鶏部位、やきとん×豚部位、牡蠣（真牡蠣/岩牡蠣×産地ブランド）、和牛、地鶏、コメ品種、酒、味噌、出汁（東西比較）、土産品 |

### その他フェーズ3項目

- アカウント機能（制覇マップ・行きたいリスト・旅程変換）
- アプリ化（Capacitor構成を `food-recommend` から流用）

## 6. KGI / KPI

### KGI（最上位・固定）

**既存事業への送客数** — `food-recommend` 登録・`deep-local` 問い合わせのうち Itadaki Atlas 経由の件数。

**PVを頂点に置かない。** 理由は `.doc/00_concept/01_north_star.md` §3。

### フェーズ別KPI

指標の定義のみ固定し、**数値目標は公開後のベースライン計測後に設定する**（根拠のない目標を先に置かない）。

| フェーズ | KPI |
| :--- | :--- |
| **1** | 公開アイテム数（180）／ GSCインデックス数 ／ オーガニック流入 ／ **地図操作率（ボトムシート展開率）** ／ SNSフォロワー数 |
| **2** | ジャンル横断回遊率 ／ フィードバック・未掲載投稿フォーム件数 ／ 地域ページ流入 |
| **3** | アカウント登録数 ／ 制覇マップ利用率 ／ **送客CV** ／ タイアップ成約数 |

計測の実装設計は `.doc/20_data/03_log_design.md`。
